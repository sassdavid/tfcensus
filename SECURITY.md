# Security policy

## Supported versions

tfcensus is pre-release. Fixes go into the next release only, so upgrade to the latest release
before you report.

## Report a vulnerability

Report it privately through GitHub's private vulnerability reporting:
[github.com/sassdavid/tfcensus/security/advisories/new](https://github.com/sassdavid/tfcensus/security/advisories/new).
Don't open a public issue, pull request or discussion for a vulnerability.

Include the version (`tfcensus version`), the command you ran and what it printed. Replace
tokens, account IDs, private repository names and other identifiers before you send it. The
report stays visible to you and the maintainer until an advisory is published.

A fix ships in a new release, and the changelog and the advisory name it.

## Verify a release

[Security and verification](https://tfcensus.sasskovacs.dev/security) shows how to check a
release's checksums, cosign signature and build provenance.
